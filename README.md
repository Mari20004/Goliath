# Goliath VPN — сайт + Telegram-бот

Один лёгкий контейнер (Python slim, SQLite, ~100 МБ образ, ~60–100 МБ RAM) + Caddy для HTTPS.

## Как это работает

1. Пользователь вводит на сайте Telegram username и телефон → получает ссылку на бота.
2. Бот просит поделиться контактом; номер и username проверяются самим Telegram (SMS не нужны).
3. Пользователь выбирает тариф → переводит по СБП с комментарием `GOL-<id>` → жмёт «Я оплатил».
4. Вам в бот приходит заявка с кнопками «Оплачено / Нет». После подтверждения сайт сам создаёт
   клиента в 3x-ui (или продлевает существующего) и показывает ссылку `SUB_BASE/<subId>`.
5. Бот напоминает об окончании подписки за 3 дня, за 1 день и в день окончания.

## Запуск на сервере

```bash
# на сервере с Docker
git clone <ваш репозиторий> goliath && cd goliath   # или скопируйте папку
cp .env.example .env && nano .env                   # заполните
docker compose up -d --build
docker compose logs -f app
```

Перед этим: направьте A-запись домена на IP сервера, откройте порты 80 и 443.
Если на сервере уже занят 80/443 — уберите сервис `caddy` и проксируйте на `app:8000` своим веб-сервером.

## Команды админа в боте (ADMIN_IDS)

- `/admin` — справка
- `/users` — последние пользователи
- `/msg @user текст` — написать любому пользователю (его ответы бот пересылает вам)
- `/all текст` — рассылка всем
- `/grant @user 3` — выдать/продлить вручную
- `/import @user subId 2026-12-31` — перенести уже выданную вручную подписку
  (для ссылки `https://submainstem.mooo.com/ytxPo-DB1NqvLBRA` subId = `ytxPo-DB1NqvLBRA`).
  Затем человек регистрируется на сайте с тем же username и получает доступ к своей подписке.

## Что учесть

- Бот работает через long polling — домен/webhook для бота не нужны.
- Панель 3x-ui должна быть доступна с сервера сайта. Для разных версий 3x-ui API может немного
  отличаться; если создание клиента вернёт ошибку — пришлите текст из `docker compose logs app`.
- Бэкапьте папку `data/` (там вся база).

## Куда развивать

Автоплатежи (ЮKassa, CryptoBot), пробный период, реферальная программа, статистика трафика
из 3x-ui, несколько серверов, админка на сайте. Структура: `app/xui.py` — панель,
`app/bot.py` — бот, `app/main.py` — API, `app/services.py` — бизнес-логика.
